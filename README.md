
# FMCG AI Business Analyst

AI 驱动的快消品经营分析与客户策略决策助手。

## 1. 项目背景

本项目模拟一家休闲食品企业的经营场景，
利用 Python、SQL 和大语言模型构建 AI 经营分析系统。

目标是实现从自然语言提问、数据查询、经营异常识别，
到客户策略分析和经营报告生成的完整流程。

## 2. 技术栈

- Python
- Pandas
- NumPy
- DuckDB
- SQL
- LLM API（后续接入）
- Streamlit（后续接入）
- Plotly（后续接入）
